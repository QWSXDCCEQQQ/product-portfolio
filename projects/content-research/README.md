# 小红书内容研究台

独立运营三个账号时，选题常从零散搜索开始，同赛道的热门话题、内容形式和参考作者需要来回核对。因此做了一个本地可视化研究台，把资料获取和结果复盘放进同一个流程。

## 两种研究路径

| 入口 | 处理过程 | 输出 |
| --- | --- | --- |
| 关键词研究 | 比较已知关键词，整理笔记和互动指标 | 关键词对比、代表笔记、对标作者 |
| 账号自动发现 | 从主页样本提取赛道词，检索、过滤并聚类同赛道笔记 | 主题地图、对标博主池、用词差集 |

主题地图使用 TF-IDF 和球形 K-means，同时展示每类样本量、互动分布和代表内容，方便读者判断某个主题是否只是被单条高赞笔记带动。原工具通过本地 MCP 读取笔记和主页，并支持导出 Markdown 报告。

## 案例验证

| 场景 | 归纳出的主题数 |
| --- | ---: |
| 科研入门 | 7 |
| 平价好物 | 5 |

两次分析共纳入 76 条同赛道样本。宽泛的关键词会引入无关笔记，小样本主题容易受少数笔记影响。根据这些结果，后续可加入人工标记无关样本和主题修正。

## 离线样例

此目录展示[主题分析模块](topic_engine.py)。在目录中用 Python 3.10 或以上版本运行：

```text
python demo.py
```

样例使用虚构标题和互动数演示聚类，无需登录或联网。安装 `jieba` 可使用中文分词，缺省时使用模块自带的字符分词。样例输出与上述真实案例的统计分开。
