# 科研启航

给第一次做论文组会的新生使用的工作流 Skill。场景是手里有几篇候选论文、汇报时间有限，需要先选文，再围绕研究问题、方法和证据组织汇报。

## 产品设计

| 阶段 | 关键判断 | 交接产物 |
| --- | --- | --- |
| 选文 | 结合用户基础、可投入时间和汇报要求比较候选论文 | 论文版本、选文理由、阅读重点 |
| 伴读 | 将概念、方法、实验结果拆成可逐步核查的任务 | 原文依据、理解检查和待核验问题 |
| 汇报 | 根据已有证据组织讲述结构，发现理解缺口时返回补读 | 汇报提纲和可供试讲的顺序 |

原型以五阶段呈现上述工作流。Skill 用统一入口按需加载三个模块，共享任务记录承接阶段之间的信息。

## 试运行

以 10 分钟组会为测试场景，比较 RAG、DPR、GraphRAG 三篇候选论文，选择 DPR 进行分步伴读。理解检查使用了「检索器找到正确段落、阅读器提取错误」的判断题，检验能否区分检索错误和答案提取错误。该轮试运行覆盖选文、伴读和理解检查。
